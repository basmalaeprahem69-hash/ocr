# عيّنات الصور

صور صغيرة مأخوذة من مجموعة البيانات الأصلية لتجربة واجهة الرفع واستخراج
«كود الطلب» دون الحاجة لتنزيل المجموعة الكاملة (~1 جيجابايت).

> تنبيه: قد تحتوي هذه الصور على بيانات شخصية من الشهادات الأصلية. إذا كان
> المستودع عاماً، يُفضّل استبدالها بنسخ مُخفية الهوية (blur/emask) قبل النشر.
